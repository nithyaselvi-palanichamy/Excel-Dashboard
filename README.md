# Blinkit Grocery Sales Dashboard – Excel

## 📌 Overview

This project presents an interactive **Excel dashboard** created using the Blinkit Grocery dataset sourced from **Kaggle**.

The dashboard was developed to analyze sales performance, understand outlet performance, track key business KPIs, and compare sales across different outlet types and locations.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Understand and compare outlet performance.
- Track key business KPIs.
- Compare sales across different outlet types.
- Analyze sales performance across different locations.
- Identify key trends and patterns in grocery sales data.

## 📊 Key Performance Indicators (KPIs)

The dashboard tracks the following key metrics:

- **Total Sales:** $1.2M
- **Average Sales:** $141
- **Number of Sales:** 8,523
- **Average Rating:** 4.0

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Sales by Outlet Type
- Sales by Outlet Location
- Sales by Item Type
- Sales by Outlet Size
- Sales Trend by Outlet Establishment Year
- Fat Content Analysis
- Fat Content by Outlet
- Comparison of Total Sales, Average Sales, and Number of Items by Outlet Type

## 🧹 Data Preparation

The dataset was prepared for analysis by:

- Renaming columns for better readability.
- Handling missing values.
- Cleaning and organizing the data for dashboard development.

## 🎛️ Dashboard Interactivity

The dashboard includes interactive slicers that allow users to filter the analysis by:

- **Outlet Size**
- **Outlet Location Type**
- **Item Type**

These filters help users explore sales performance across different outlet characteristics and product categories.

## 💡 Key Insights

- The dashboard generated an overall **Total Sales of $1.2M** with an **Average Sales value of $141**.
- **Tier 3 outlets** recorded the highest sales among outlet locations, contributing approximately **$472.13K**.
- **Medium-sized outlets** generated the highest sales at approximately **$507.90K**.
- **Fruits and Vegetables** were the highest-selling item category, generating approximately **$178.12K**, followed by **Snack Foods** at approximately **$175.43K**.
- Regular-fat products contributed a larger share of sales compared with low-fat products.
- Outlet establishment sales peaked in **2018**, reaching approximately **$204.52K**.
- The dashboard enables comparison of outlet types based on **Total Sales, Average Sales, and Number of Items**.

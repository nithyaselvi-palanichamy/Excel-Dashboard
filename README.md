# Excel Data Analysis & Lookup Functions Task

## 📌 Overview

This repository contains an Excel task completed during my **Business Data Analytics training**. The task focused on analyzing, cleaning, and arranging data and using Excel lookup functions to retrieve related information dynamically.

The objective was to create an interactive output where selecting a person's name displays their corresponding details, such as **Email ID, Purchase Details, Amount**, and other related information.

## 🛠️ Excel Functions & Features Used

* VLOOKUP
* XLOOKUP
* INDEX + MATCH
* IF Function
* FILTER Function
* Data Validation Dropdown
* Conditional Formatting

## 🔄 Task Workflow

1. Analyzed the given dataset.
2. Cleaned and organized the data.
3. Arranged the data into a structured format.
4. Applied lookup functions to retrieve related information.
5. Created a Data Validation dropdown to select a person's name.
6. Displayed the corresponding details dynamically.
7. Used Conditional Formatting to improve data visibility and presentation.

## 📊 Task Output

When a name is selected from the dropdown, the corresponding information is automatically displayed, including:

* Email ID
* Purchase Details
* Amount
* Other related details

This task demonstrates the practical application of Excel lookup functions and data handling techniques to create a user-friendly and dynamic data retrieval solution.
